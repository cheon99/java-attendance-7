# ER, 인터페이스 , 객체 설계
학생 하나는 출석 기록(날짜 + 등교 시각)을 여러개 가진다 
출석 기록은 지각/결석 판정 하나를 종속시킨다  
출석 부는 학생 목록을 가진다 
학생은 자신의 지각/결석 횟수를 반환하는 인터페이스를 가진다
학생은 출석 기록을 수정할 수 있는 인터페이스를 가진다 
학생은 출석 기록을 추가/수정/조회하는 책임을 진다 
출석 부는 징계를 판정할 수 있다 
출석 부는 입력을 그대로 받아 올바른 형식, 로직인지 검증한다 
컨트롤러는 UI를 제공하고 입력을 핸들링하며 출석부 서비스를 이용한다

# 비즈니스 로직
- 교육 시간
  - 월요일은 13:00 ~ 18:00, 화~금요일은 10:00 ~ 18:00
- 지각/결석 판정 
  - 지각 : 교육 시작 시간으로부터 5분 초과
  - 결석 : 교욱 시작 시간으로부터 30분 초과, 혹은 출석 기록 없음
- 경고/면담/제적 판정
  - 지각 3회는 결석 1회로 판정한다
  - 경고 : 결석 2회 이상
  - 면담 : 결석 3회 이상
  - 제적 : 결석 5회 초과
캠퍼스 운영 시간은 매일 08:00~23:00
주말 및 공휴일에는 출석을 받지 않는다.

# 프로그래밍 준수 사항
- [] indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다
- [] 3항 연산자를 쓰지 않는다
- [] 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다 (함수(또는 메서드)가 한 가지 일만 잘 하도록 구현)
- [] else 예약어를 쓰지 않는다
- [] Java Enum을 적용하여 프로그램을 구현한다
- [] 구현한 기능에 대한 단위 테스트를 작성한다. 단, UISystem.out, System.in, Scanner) 로직은 제외한다.
## 라이브러리
camp.nextstep.edu.missionutils 에서 제공하는 DateTimes 및 Console API 를 사용하여 구현해야 한다.
현재 날짜와 시간을 가져오려면 camp.nextstep.edu.missionutils.DateTimes 의 now() 를 활용한다.
사용자가 입력하는 값은 camp.nextstep.edu.missionutils.Console 의 readLine()을 활용한다.
